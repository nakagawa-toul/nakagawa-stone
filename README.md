# 中川石材 業務管理Webアプリ（試作版）

石材店の「今日の対応（支払い・返信・工事準備・経理）」「工事・お客様案件」「今後の資金繰り見通し」「作業履歴・弥生会計入力」を一元管理できるWebアプリの試作品です。

---

## 1. はじめに（試作版と本運用の違い）

> [!IMPORTANT]
> **本アプリは「端末内保存（LocalStorage）」で動く試作品です。**
> - **現在（試作版）**: 外部サーバーへの接続や有料契約なしで動作します。入力・編集したデータはお使いのブラウザ内部に安全に保存され、再読み込みしても消えません。ただし、別のスマホやPCとは自動同期されません。
> - **将来（本運用）**: クラウドデータベースを接続し、「夫が現場スマホで入力した内容が事務所の私のPCに即座に共有される」複数端末リアルタイム同期に切り替えます。

## 2. 起動方法（初心者向けガイド）

### 方法A: 最も簡単な方法（Macのブラウザで直接開く）
1. MacのFinderで以下のフォルダを開きます：
   `/Users/nakagawaminorutsuru/.gemini/antigravity/scratch/nakagawa-stone-app`
2. `index.html` をダブルクリック（または右クリックしてSafariやGoogle Chromeで開く）します。
3. これだけで即座にアプリが立ち上がり、全機能をお試しいただけます。

### 方法B: スマホの実機で操作感を試す方法（ローカルサーバー起動）
Macとスマートフォンが同じWi-Fiに接続されている場合、スマホ実機で片手操作の感覚を試すことができます。

1. Macの「ターミナル」アプリを開きます。
2. 以下のコマンドを実行します：
   ```bash
   cd /Users/nakagawaminorutsuru/.gemini/antigravity/scratch/nakagawa-stone-app
   ./start.sh
   ```
3. 画面に表示される `http://192.168.x.x:8080` のようなアドレスをスマホのブラウザ（Safari等）に入力してください。
4. スマホの画面でサクサク動く業務管理画面が開きます。
   ※ 終了する際は、Macのターミナルで `Control` + `C` を押してください。

## 3. 試せる機能

### ① ホーム／今日の対応
- **期限超過のアラート**: 期限が過ぎた仕事（工事届、振込など）を赤バッジと警告音・アニメーションで最上部に表示。漏れを即座に防ぎます。
- **今日中・今週中の絞り込み**: 「今日何をするか」をワンタップで確認できます。
- **支払い・返信・工事準備・経理の統合管理**: 石材店特有の仕事をカテゴリ別に色分け表示。
- **次にすること**: 「具体的に次は何をするか」がひと目でわかる枠を配置。
- **ワンタップ完了 & 取消**: チェックボタンを押すと完了になり、間違えて押しても取消可能です。完了すると作業履歴にも自動反映されます。
- **追加・編集・削除**: 親指で押しやすい下部追加ボタン（スマホ）や右上の編集ボタンからいつでも変更できます。

### ② お金の管理（本格「月次資金繰り表」＆「何に使っているか支出分析」）
- **石材店特化の「月次資金繰り予定・実績表（マトリクス）」**:
  - 税理士対応や金融機関の融資交渉、自社の資金管理でそのまま使える標準フォーマット。
  - **前月繰越預金残高**
  - **【Ⅰ 営業収入の部】**: 墓所新設代（着工・完工）、改修代、戒名彫刻・納骨料、墓じまい代、その他
  - **【Ⅱ 営業支出の部】**:
    - ［原価・仕入・工事費］石材仕入代、基礎建材費（生コン・砕石等）、重機リース、字彫り外注費
    - ［人件費］給与手当・専従者給与・賞与
    - ［固定費・現場経費］車両費・軽油代、切削砥石・消耗品、損害保険料、事務所通信光熱費
    - ［財務・税務］公庫・地銀借入金返済、租税公課・消費税積立
  - **【Ⅲ 当月収支差額】**（収入計 − 支出計）
  - **【Ⅳ 月末預金残高（翌月繰越）】**
  - 表の中の金額セルをクリックすると、下部に**該当する個別取引明細（相手先、日付、金額、予定/実績、案件名）がスッと展開表示**されます。
  - 「印刷」ボタンからA4紙やPDFで綺麗に出力可能。

- **何にいくら使っているかの「費目別 支出構成分析」**:
  - ドーナツチャートで費目ごとのシェアを視覚化。
  - 「石材仕入代が42%」「人件費が33%」「重機・建材が15%」といった構成比ランキング・金額・プログレスバーを表示。
  - 「今後3か月全体」「10月度」「11月度」「12月度」「1月度」と月ごとにワンタップで絞り込み分析ができます。

- **残高推移・未入金・未払い・全取引明細**:
  - 日別の残高シミュレーション折れ線グラフ。
  - 基準日（2026/10/31）以前の取引は二重計上されない安全設計。
  - 回収予定の「未入金」と支払期日の迫る「未払い」をワンタップで実績化。
  - 利益（損益）と口座残高（手元資金）の違いについての解説を常設。

### ③ 工事・お客様の管理
- **案件一覧**:
  「佐藤家 墓所新規建立」「田中寺様 歴代住職墓補修」などの案件名、施主名、墓所場所、工期、担当者、進捗ステータスを管理。
- **Google Driveリンク**:
  「CAD図面」「見積書」「請求書」「現場写真」のGoogle Driveフォルダをボタン1つで開けます。
- **関連タスク・収支の自動ひも付け**:
  案件カードをクリックすると、その工事に関連する「今日のタスク」「入出金予定」だけをまとめて確認できます。

### ④ 作業履歴・弥生会計の進捗記録
- **時系列タイムライン**:
  「いつ、誰が、何をしたか」が自動的に残ります。
- **クイック記録ボタン**:
  「振込完了」「メール返信」「現地寸法測定」などをワンタップで現在時刻・担当者付きで記録。
- **弥生会計専用の記録フォーム**:
  「対象月（例: 9月分）」「資料の種類（通帳・カード明細）」「完了範囲」「残作業・夫への確認事項」を入力し、経理の進捗を明確に残せます。
- **音声入力対応**:
  マイクボタンを押すか、スマホのキーボードの音声入力マイクを使って、現場や移動中でも声で素早くメモできます。
- **過去ログの検索**:
  キーワードや担当者で過去の作業を瞬時に検索できます。

### ⑤ 重要メール
- **石材店に合わせた架空メール**:
  石材卸問屋からの納期回答、寺院からの相談、霊園管理事務所からの通知などを再現。
- **「既読」と「対応済み」の分離**:
  「メールを読んだ（既読）けれど、返信や手配を忘れていた」という漏れを防ぐため、既読と対応済みを別々に管理。
- **メールからタスクへワンクリック登録**:
  メールを開いて「今日の対応に登録」を押すと、件名や期限を引き継いだタスクがホームに自動追加されます。

### ⑥ 権限制御の疑似体験（操作者の切り替え）
画面右上の「操作者」プルダウンで切り替えを体験できます：
1. **私（管理者・経理）**: 全画面・全データ（資金情報・メール含む）の閲覧・編集が可能。
2. **夫（現場・工事担当）**: 現場スケジュール、案件、タスク、作業履歴を中心に操作。
3. **スタッフ3人目（閲覧限定）**: 案件や工事日程、タスクは確認できますが、**「お金の管理」と「重要メール」は権限エラーで完全に非表示**になります。

## 4. 本運用（実運用）に向けた提案書

試作品の検証後、本格的にご家族・スタッフ間で共有運用する際の設計案です。

### 1. 個別ログインと厳格な権限制御（画面を隠すだけではない設計）
- **なぜ画面隠しだけでは駄目なのか**:
  単に画面上のボタンやタブを非表示にするだけでは、詳しい人がブラウザの開発者ツールを見れば裏で流れている口座残高や取引先の金額が見えてしまいます。
- **本運用のセキュリティ設計（RLS: Row-Level Security）**:
  データベース層で「スタッフ3人目のIDには、資金テーブルやメールテーブルのデータを1文字も送信しない」という厳格なアクセス制御（行レベルセキュリティ）を設定します。これにより、スマホを紛失したり不正アクセスされたりしても機密情報が絶対に漏れません。

### 2. 共有データ保存（クラウドデータベース）
- **推奨技術**: **Supabase（または Firebase）**
  - PostgreSQLという堅牢なデータベースをベースにした安全なクラウド基盤です。
  - スマホとパソコンの間で、変更が1秒以内にリアルタイム同期されます。
  - 暗号化通信（SSL/TLS）および自動バックアップ（日次バックアップ）が標準装備。

### 3. バックアップ体制
- クラウドデータベースの自動バックアップ（過去7日間〜30日間の状態にいつでも巻き戻し可能）。
- 週1回、経理・案件データをCSVまたはExcel形式で自動出力し、指定のGoogle Driveフォルダに保存する二重バックアップ設計。

## 5. 後から追加する機能（今後のロードマップ）

試作版の操作感にご納得いただけた後、以下の順序で段階的に拡張します：

1. **Gmail自動連携**:
   - Google Workspace / Gmail APIと接続し、「石材」「墓地」「施主名」などの重要メールを自動抽出。
   - 広告やMツールの通知は自動で別フォルダに分類（削除はせず確認可能）。
   - 分類ミスがあれば手動で修正できるようにし、期限不明・要確認メールも拾い上げる。
2. **既存Mツール（スプレッドシート＋GAS）との連携**:
   - Mツールのお客様名や工事予定日を本アプリへ自動インポート（既存ファイルやGASは一切変更不要）。
3. **写真・領収書添付**:
   - スマホのカメラで撮影した現場写真やレシートを、案件・取引レコードに直接添付（Google Driveへ自動保存）。
4. **LINE / メールによる通知機能**:
   - 期限当日の朝に「今日のやること」をご夫婦それぞれのLINEへ自動通知。
